# Live Compte

Live Compte est une application de gestion de trésorerie en temps réel, développée avec React et Vite. Ce projet met en avant mes compétences en développement front-end, en gestion d'état et en intégration d'outils modernes comme TailwindCSS et Flowbite.

## Fonctionnalités

- **Gestion des transactions** : Ajout, filtrage et affichage des recettes et dépenses.
- **Filtrage avancé** : Filtrage par libellé, par mois ou entre deux dates.
- **Export PDF** : Impression ou export des données sous forme de tableau.
- **Stockage persistant** : Conservation des données grâce au `localStorage`.

## Technologies utilisées

- **React** : Bibliothèque JavaScript pour construire des interfaces utilisateur.
- **Vite** : Outil de build rapide pour les projets modernes.
- **TailwindCSS** : Framework CSS utilitaire pour un design rapide et réactif.
- **Flowbite** : Composants UI prêts à l'emploi basés sur TailwindCSS.

## Installation

1. Clonez le dépôt :
   ```bash
   git clone <url-du-repo>
   ```
2. Accédez au dossier du projet :
   ```bash
   cd live-compte
   ```
3. Installez les dépendances :
   ```bash
   npm install
   ```
4. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```
5. Ouvrez votre navigateur à l'adresse suivante :
   ```
   http://localhost:5173
   ```
